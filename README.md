# Inktion

A 2D animation app for drawing, rigging and animating, for macOS and Windows.

**[Download the latest release →](https://github.com/HotcakeHooligan/inktion-releases/releases)**

- **macOS** (Apple silicon): download the `macos-arm64.zip`, unzip it and move Inktion to Applications. The first time you open it, right-click it and choose **Open**.
- **Windows** (64-bit): download the `windows-x64.zip`, unzip it and run `Inktion.exe`.

Inktion updates itself: it checks for new versions when it opens (Help › Check for Updates…).

Inktion is in beta. This repository only hosts releases.
